# Demo gallery

Looping clips of runnable demos: each one is a short script in [`examples/demos/`](../examples/demos/); click a preview for the MP4.

Every demo takes the same options: `--device` (default `cuda`), `--worlds`, `--size` (the video frame, `WxH` or one number for a square; a batch is tiled on it), `--frames` (30 per second) and `--out`; scene demos also take `--scene`: a benchmark scene (`franka`, `showcase`, `sponza`, downloaded on first use by [`benchmarks/run.py`](../benchmarks/README.md)), a fixture of [`tests/data/scenes/`](../tests/data/scenes/README.md) (`cornell_rect`, `open_plan`, ...) or a scene file. Run them from a repository checkout with `pip install "raywarp[all,video]"`; each one also runs with `--device cpu` at a tiny size (`--worlds 2 --size 96x64 --frames 3`), which is how `tests/tooling/test_demos.py` checks them. The clips were recorded on an RTX GPU with the commands shown.

## More

- **mjlab**: raywarp is an RGB backend of mjlab's camera sensors (`RaywarpCameraSensorCfg`, [quickstart](quickstart.md#mjlab)); no demo here (it needs a CUDA device and mjlab).
- **Isaac Lab**: pick raywarp as a camera's renderer with `RaywarpRendererCfg` ([quickstart](quickstart.md#isaac-lab)); no demo (it needs an Isaac Lab install).
- **Web viewer**: `raywarp view SCENE` opens any scene in the browser ([CLI](cli.md)); the clip is a screen recording.
